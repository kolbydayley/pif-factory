## Interpretation boundaries

Scores select candidates for design review, not automatic release. In particular: debate/stance/changed-mind options require proposition matching and adjudication; notification options require explicit delivery setup; personalized options require private state; statistical intervals require a defensible estimator. The current extraction event contract alone supplies none of these guarantees.

The assembled experience must have only one primary job per page, one visible scope per chart/claim group, a bounded overview, and a direct source path. Do not simply put every high-scoring component on every page. Preserve the editorial shell and familiar entity routes unless a competing complete architecture improves the actual user journeys.
